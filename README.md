# 🎯 InterviewBuddy AI

AI-powered interview preparation platform that helps you ace your next job interview.

![InterviewBuddy AI](./public/images/og-image.jpg)

## ✨ Features

- 🤖 **AI-Generated Questions** - Personalized questions based on your resume
- 🎤 **Voice Mode** - Practice speaking with real-time transcription
- 📊 **Analytics Dashboard** - Track your progress over time
- 📝 **Resume Analysis** - Upload PDF and get tailored questions
- 💯 **Detailed Scoring** - Communication, technical, and confidence scores
- 🌙 **Modern UI** - Glassmorphism design with smooth animations

## 🛠️ Tech Stack

- **Frontend:** React 19, TypeScript, Tailwind CSS 4
- **Backend:** Supabase (Auth, Database, Storage)
- **AI:** Google Gemini API
- **State:** Zustand
- **Animations:** Framer Motion
- **Charts:** Recharts

## 🚀 Quick Start

```bash
# Clone
git clone https://github.com/YOUR_USERNAME/interviewbuddy-ai.git
cd interviewbuddy-ai

# Install
npm install

# Configure environment
cp .env.example .env
# Add your API keys to .env

# Run
npm run dev
